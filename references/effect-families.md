# 按参考选择特效实现

| 特效 | 从参考测量 | UE 第一版 | 最容易看出差异的动作 |
| --- | --- | --- | --- |
| 移动拖尾、飘散碎屑 | 头部位置、速度变化、尾部保留秒数、沿程宽度 | 头部附着，脱落粒子在世界空间模拟。连续线用 Ribbon，独立晶片用 Sprite 或 Mesh。按距离或时间发射取决于参考里速度与密度的关系 | 急转弯，停下后的尾迹 |
| 定点爆发、冲击环 | 触发帧、圆心、半径随时间的变化、环宽、最后可见帧 | Niagara 单次 Burst，固定发射源。规则环先用带径向遮罩的平面或网格，粒子年龄驱动半径、边宽和透明度。碎片另开短寿命发射器 | 触发前一帧、峰值、消失后是否又闪一次 |
| 持续光场、烟雾 | 起效过渡、稳定段密度、流向、停止发射后的衰减 | 分开控制启动、稳定、退出。旋转或噪声驱动流动，User 参数控制强度。烟雾先比较明度和遮挡，再决定 Sprite、体积材质或 Niagara Fluids | 刚启动、稳定段、主动关闭 |
| 光束、电弧 | 两端挂点、分支、闪烁频率、弯折幅度 | 独立传入起点和终点，用 Beam/Ribbon 或网格材质，给分支设置独立寿命 | 只移动其中一个端点，观察中段和末端 |
| 动作刀光、贴身特效 | 挥动的首尾帧、武器两端的扫掠面、遮挡 | 用动画通知控制开启和结束，采样骨骼或 Socket。需要宽弧面时从两端构建带状几何 | 动作变速、转身、武器经过身体前后 |
| 屏幕扭曲、闪白、叠层 | 图案是否随镜头固定、覆盖范围、边缘位移、UI 是否受影响 | 依据合成顺序选后处理材质或 UMG，时间曲线控制强度。有世界空间遮挡时单独处理遮罩 | 移动镜头，观察 UI 与几何边缘 |

记录源文件、有效裁切、时间段、真实 UE 版本、资产及关卡路径、捕获 take；补充复位方法和最有用的可调参数。单个视角看不到的深度、光照或背面行为标明推测。

粉晶拖尾案例中，鼠标是运动参考点，亮度重心容易落在上一段发光尾迹上。遇到新视频，先确认哪个物体代表发射源；固定圆心的冲击环直接量半径即可。头尾颜色、裁切框、摄像机比例及运动键都从新参考重新取样。
